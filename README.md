
# CSI201 – Networked Quiz Tournament

**Coursework I | Group 26**

## Project Overview

A multiplayer command-line quiz tournament developed using Python 3.12 and raw TCP sockets. The system supports multiple quiz rooms, timed questions, automatic scoring, host transfer and leaderboards.

## Repository Structure

- [Codes](Codes/) – Source code, question bank, automated tests and running instructions.
- [Documentation](Documentation/) – Development documentation.
- [Test Evidence](Test_Evidence/) – Docker test results and CLI screenshots.

## Running the Project
